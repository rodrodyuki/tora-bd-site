# Birthday Quiz Site

## 目的
references/plan.md の仕様に沿って、誕生日向けクイズサイトを構築・更新する。

## ワークフロー

1. 事前確認を行う。
2. 仕様を読み込む。
3. 実装・更新する。
4. 動作確認する。
5. 成果物を保存する。

### 1. 事前確認
必ず次の2点を質問する。
- クイズ内容は `references/plan.md` のままでよいか。変更があれば内容を教えてもらう。
- 誕生日サイトに載せる人の名前を変えるか。変更があれば正式な表記を教えてもらう。

### 2. 仕様の読み込み
- `references/plan.md` を読み、デザイン・クイズ・演出の要件を把握する。
- ユーザーから変更指示があれば、`references/plan.md` の内容より優先する。

### 3. 実装・更新
- 既存ファイルがある場合はそれを優先して編集する。
- 外部ライブラリを使わず、単一HTMLまたは同一フォルダ内のJS/CSSで完結させる。
- レスポンシブ対応、ピンク/ブルー基調、アイコン散りばめを反映する。
- クイズは6問の3択で、正解するまで次へ進めないようにする。
- 不正解時はヒント/応援メッセージ、正解時は褒め言葉を表示する。
- 指定がある設問は正解後に解説メッセージを表示する。
- 全問正解後に大きな祝福テキスト、紙吹雪、`celebration.mp4` の再生UI、締めメッセージを表示する。
- 自動再生制限に配慮し、動画の再生ボタンを必ず用意する。

### 4. 動作確認
- モバイルとデスクトップで表示崩れがないことを確認する。
- クイズの進行制御、メッセージ表示、全問正解後の演出を確認する。
- 動画がローカルファイルとして再生できることを確認する。

### 5. 成果物の保存
- スキルフォルダ直下に `outputs` が無ければ作成する。
- `outputs/YYYYMMDD-HHMMSS/` を作成して成果物をコピー保存する。
- コピー対象は、作成・更新したHTML/CSS/JS/画像/動画などの配布ファイル一式とする。
